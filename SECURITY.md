# Security Policy

## Supported Versions

The following versions of this project are currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| main (latest) | :white_check_mark: |
| older branches | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

1. Do not open a public issue.
2. Email the maintainer with:
   - A clear description of the issue
   - Steps to reproduce
   - Potential impact
   - Any suggested remediation
3. Allow reasonable time for triage and remediation before public disclosure.

If you cannot find a private contact method in this repository, open a minimal public issue asking for a private security contact channel without sharing exploit details.

## What to Expect

- Initial acknowledgment: within 7 days
- Triage update: within 14 days (when reproducible)
- Fix timeline: depends on severity and complexity

We appreciate responsible disclosure and your help keeping this project and its users safe.
